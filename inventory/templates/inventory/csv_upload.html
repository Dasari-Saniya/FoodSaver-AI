File Format Specifications

Your CSV must include the following headers in row 1:

Column Header Required? Format / Example
food_name Required e.g. Whole Milk, Sourdough
quantity Required Numeric > 0 (e.g. 12.50)
expiry_date Required YYYY-MM-DD or DD-MM-YYYY
category Optional Produce, Dairy, Bakery, Meat, Seafood, Pantry...
unit Optional kg, g, lbs, units, packs, litres, boxes, cans
batch_number Optional e.g. LOT-2026-A1
storage_location Optional e.g. Cold Room 1, Shelf B
description Optional Handling instructions or allergen notes
